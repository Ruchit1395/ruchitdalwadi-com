# AI-Native Team Work Campaign

Purpose: teach founders, PMs, operators, and AI builders how to make everyday company work AI-native without exposing any private company, team, customer, system, or data details.

## Cadence

- X: one native post every IST day at 19:00.
- LinkedIn: one native post every IST day at 19:20.
- Both platforms use the same numbered lesson on a given day, but the wording, opening, paragraph order, and ending must be platform-native.
- Never post the same text verbatim on both platforms.
- Never publish more than one native post per platform per IST day.

## Campaign assets

- `POST_BANK.md`: 36 finished core posts in campaign order.
- `POST_QUEUE.csv`: per-platform publication state and URLs.
- `RUNBOOK.md`: selection, privacy, drafting, browser publishing, and recovery rules.
- `PRIVACY_AND_LANGUAGE_RULES.md`: hard bans for this campaign.
- `WORKLOG.md`: durable run history.

The shared voice rules remain authoritative:

## Reporting contract

```text
X:
- New post: count and URL, or None.
- New comments: None.
- Replies: None.
- Stats updated: count and URLs, or None.

LinkedIn:
- New post: count and URL or stable identifier, or None.
- New comments: None.
- Replies: None.
- Stats updated: count and URLs, or None.

Status: next campaign day, remaining blockers, and repository state.
```
